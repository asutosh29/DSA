# Q2. Create a Sorted List

> **Question:** Write a function `create_sort()` which creates a **sorted list**. A single data item may be an `integer` or `float`, and each item is received from the standard input device. Print the resulting list.

## Approach

`create_sorted()` first reads how many elements `n` to expect, then reads `n` numbers one by one. Each element is inserted into the list **at its correct sorted position** as it arrives, using `insert_sorted()` — the same insertion logic as Q8. Because every insert maintains ascending order, the final list is always sorted regardless of the input order.

- **`create_sorted()`** — reads `n`, then calls `insert_sorted()` for each value.
- **`insert_sorted()`** — finds the first node whose data is `>=` the new value and inserts before it; if the new value is smaller than the head, it becomes the new head.

## Integer OR Float Support

The data type is **`double`**, which can hold both integers and floats exactly (every `int` fits in a `double`). So `cin >> temp` accepts both `5` and `5.5` with no special handling, and the `<` / `>=` comparisons work identically for both. No extra logic is needed — the type change alone satisfies the "integer or float" requirement.

## Notes

- `create_sorted()` is O(n²) overall — O(n) for each of the n insertions — which is fine for this worksheet.
- Duplicates are placed *after* existing equal elements (the scan stops only when `curr->next->data < data` is false), so equal values keep their relative input order.
- `cout` prints whole doubles like `5` as `5` and fractional ones as `5.5`, so outputs stay readable.
