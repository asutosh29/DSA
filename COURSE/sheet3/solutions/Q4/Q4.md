# Q4. Search with Previous Pointer

> **Question:** Modify the function from **Q3** so it also makes available, to the calling function, two pointers:
> - A pointer to the **key node**.
> - A pointer to the **node previous to** the key node.

## Approach

The search function returns a `SearchAnswer` struct containing **two pointers**:
- `curr` — the node holding the key (`nullptr` if not found),
- `prev` — the node immediately before it (`nullptr` if the key is the first node).

The scan keeps track of `prev` as it walks; when `ptr->data == key`, both pointers are packaged and returned. If the key is never found, `curr` is `nullptr`.

`main()` then prints:
- `data found!` + `Element previous to key is: X` when the key exists and has a predecessor,
- `data found!` + `Element previous to key doesn't exist!` when the key is at the head,
- `Element not found!` otherwise.

## Source

`COURSE/sheet3/4.cpp` — rewritten with core logic unchanged. The original function was misleadingly named `insert_after()` even though it only performs a search; it has been renamed to **`search_with_prev()`** for clarity. No search logic was changed.

## Representations

Two versions are provided, identical in logic and prompts:

- **`Q4.cpp`** — pointer representation (`Node*`), from `COURSE/sheet3/4.cpp`.
- **`Q4_array.cpp`** — linked-array representation (`data[]` + `next_index[]`), from `THEORY/LL/LinkedArray/larray.cpp`. The two "pointers" are array indices; `NIL (-1)` plays the role of `nullptr`, and `SearchAnswer` holds `prev`/`curr` indices.

## Test Cases

| # | Input (one line each) | Expected Output | Covers |
|---|-----------------------|-----------------|--------|
| 1 | `10`, `20`, `30`, `-99` then key `10` then `-99` | `10 found!` + `Element previous to key doesn't exist!` | Key at head → `prev` is nullptr |
| 2 | `10`, `20`, `30`, `-99` then key `20` then `-99` | `20 found!` + `Element previous to key is: 10` | Key in middle, has predecessor |
| 3 | `10`, `20`, `30`, `-99` then key `30` then `-99` | `30 found!` + `Element previous to key is: 20` | Key at tail |
| 4 | `10`, `20`, `30`, `-99` then key `99` then `-99` | `Element not found!` | Key absent |
| 5 | `-99` then key `5` then `-99` | `List is empty` → `Element not found!` | Empty list |
| 6 | `7`, `7`, `9`, `-99` then key `7` then `-99` | `7 found!` + `Element previous to key doesn't exist!` (first `7` is at head) | Duplicate keys — returns first occurrence |

## Notes

- When the key is not found, `prev` points at the last node of the list (trailing value) but `curr == nullptr` signals "not found", so `prev` is ignored by `main()`.
- The `SearchAnswer` object is heap-allocated (as in the original); the program does not free it, which is acceptable for a worksheet program.
