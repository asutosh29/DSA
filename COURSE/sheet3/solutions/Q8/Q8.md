# Q8. Insert into a Sorted List

> **Question:** Further modify the above function so that it receives the head pointer to a **sorted list** and a data item, and inserts the data item at its **appropriate place** in the sorted list (maintaining sort order).

## Approach

`insert_sorted(head, data)` finds the correct spot in the ascending list:

1. If the list is empty, or `head->data >= data`, the new node becomes the new head (it is smaller than or equal to the current smallest).
2. Otherwise, walk with `curr` while `curr->next->data < data` — i.e. stop right before the first node that is `>= data`.
3. Splice the new node in after `curr`.

This maintains ascending order after every insert. The head can change, so the function returns it.

`main()` uses a simple loop: each iteration asks for an element to insert, prints the list, and repeats until the user enters `-99` to exit.

## Test Cases

| # | Input (one line each) | Expected Output | Covers |
|---|-----------------------|-----------------|--------|
| 1 | Empty list (`-99`), then `15`, then `7`, then `-99` | `List is empty!` + `Add elements to the list:` → `15` → `7 15` | Empty list, then add elements |
| 2 | List `10 20 30`, then `5`, then `-99` | `5 10 20 30` | Smaller than head → new head |
| 3 | List `10 20 30`, then `25`, then `-99` | `10 20 25 30` | Between two nodes |
| 4 | List `10 20 30`, then `40`, then `-99` | `10 20 30 40` | Larger than all → append |
| 5 | List `10 20 30`, then `20`, then `-99` | `10 20 20 30` (equal value goes *after* the existing 20) | Duplicate value |
| 6 | List `5 15`, then `10`, then `1`, then `-99` | `5 10 15` then `1 5 10 15` | Multiple inserts build the sorted list |
| 7 | List `-5 0 7`, then `-10`, then `-99` | `-10 -5 0 7` | Negative values |

## Notes

- Duplicate values are placed **after** existing equal nodes (the scan stops at the first `curr->next->data >= data`, so an equal value lands after all existing equals — except when it is smaller than the head, where it becomes the head).
- Insert is O(n) worst case; building a list of `n` items this way is O(n²).
