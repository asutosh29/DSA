EEO - 101: DATA STRUCTURES
                         Worksheet – 2  Review Do it Yours	elf
1. Write a function which receives
- a sorted array of integers & 
- a Pointer to an integer data .
The function shall insert this received data at an appropriate place in the sorted array; access array elements using pointer. 
2. Write a test main program to allocate a block of data using dynamic memory allocation using malloc ( ) and calloc( ) functions . Also test realloc( ) function for all possibilities of modifying the allocated block size.
3. Define a structure to store the following  desired information regarding  all the students admitted  for  M. Tech.  Program at electrical engineering  department

Name of Student, Father’s Name, Enrollment No., 
Specialization, Major/s, Minor/s 
Gate Score , Status Category, Bhawan allocated, Room No. 
Home address having;  House No., Street, City , State, Pin code, 
Blood Group.
Also write a small  program to store  the  data  using DMA and  display  it on output device to  validate the  same for at least 15 selected students.
4. Write a function which receives a character string, and, changes all letters to upper case letters; no library function to be used for conversion.
5. Repeat Q.4 to change all characters to lower case.
6. Repeat Q. 4 to change lowercase letters to uppercase & uppercase to lowercase.
7. Write a function to reverse a character string.
8. Write a function which receives a character string and checks if it is palindrome.
9. Write a function which receives a numeric array and rotates it by given number of positions.
10. Write a function to reverse a given array of pointers to group of strings.
11. Define a suitable structure to represent a complex number and write functions.
 	Add_cmplx		to add two complex operands
	Mult_cmplx		to multiply two complex operands
	Div_cmplx		to divide two complex operands
	Negate			to get a complex conjugate of a complex number
All these functions should receive pointer to structure of complex operands required.

Note: As for as possible try to use pointers to access the variables in  functions. Test all the functions Q.4 – Q. 11 by writing a suitable main program.
