# Q11. Intersection of Two Sorted Lists

> **Question:** Given two sorted linked lists, write a function to find their **intersection**.

## Approach

Both lists are sorted ascending, so a **two-pointer merge walk** works in a single pass:

- `c1` walks list 1, `c2` walks list 2.
- If `c1->data == c2->data` → common element: append a copy to the result list, advance **both** cursors.
- If `c1->data > c2->data` → advance `c2` (its value can't match anything smaller ahead in list 1).
- Else → advance `c1`.

When either list runs out, there can be no more common elements. The result is a new list of the common elements, in sorted order, with duplicates preserved (e.g. `1 2 2 3` ∩ `2 2 4` = `2 2`).

## Notes

- Both input lists must already be sorted for the algorithm to be correct.
- Time complexity is O(len(L1) + len(L2)); the result is a fresh list (the inputs are not modified).
