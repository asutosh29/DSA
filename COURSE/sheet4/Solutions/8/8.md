# Q8. Tower of Hanoi (Recursive) — `Tower()`

> **Question:** Write a function `Tower()` to demonstrate the **Tower of Hanoi** problem using **recursion**.

## Approach

Three **array stacks** represent the three pegs (`beg`, `end`, `aux`). Each stack stores disk sizes, largest at the bottom. `test_tower(n)` first fills `beg` with `n` disks (`n`, `n-1`, ..., `1`), then calls the recursive `Tower()`:

- **Base case (`n == 1`)** — pop the top disk from `beg`, push it onto `end`.
- **Recursive step** —
  1. move the top `n-1` disks from `beg` to `aux` (using `end`),
  2. move the largest disk from `beg` to `end`,
  3. move the `n-1` disks from `aux` to `end` (using `beg`).

Every disk move is a `pop()` followed by a `push()`, so the "larger disk never sits on a smaller one" rule is naturally preserved by recursion. The array-stack primitives (`underflow/overflow/push/pop`) are the same as in Q1(i).

## Test Cases

| # | Input (`n`) | Expected Output | Covers |
|---|-------------|-----------------|--------|
| 1 | `0` | `Number of disks must be positive!` and exit | **Failure: zero disks rejected** |
| 2 | `-3` | `Number of disks must be positive!` and exit | **Failure: negative disks rejected** |
| 3 | `1` | `Moved 1 from beg to end` (1 move) | Base case |
| 4 | `2` | 3 moves: disk 1, disk 2, disk 1 | Recursion with 1 auxiliary disk |
| 5 | `3` | 7 moves: 1, 2, 1, 3, 1, 2, 1 | Standard 3-disk solution (2³ − 1) |
| 6 | `4` | 15 moves (2⁴ − 1), largest disk moved exactly once, in the middle | General `n` |

## Notes

- The minimum number of moves is `2^n − 1`. A valid run for `n` disks always shows exactly that many `Moved` lines.
- The move messages follow the original `8.cpp` exactly (`from beg to end` for every move) — the recursion alternates the roles of the stacks, so the destination peg is always printed as `end`.
- The largest disk is moved exactly once, exactly halfway through the sequence.
