# Q10. Doubly Linked List Insertion

> **Question:** Write and test a function `insert_DLL()` to implement insertion in a **doubly linked list**. Incorporate **all variations** of insertion (at head, at tail, before a node, after a node, at a given position, etc.) and list them clearly.

## Status: COMPLETED

The original `COURSE/sheet3/10.cpp` only had `create_dll()` and `print()`; `insert_before()` / `insert_after()` were declared but never implemented, and there was no `insert_DLL()`. This file now implements the full set of insertion variations.

## Insertion Variations Implemented

| # | Function | Behavior |
|---|----------|----------|
| 1 | `insert_at_head(list, data)` | Inserts at the **head**; new node becomes the new head (also handles empty list). |
| 2 | `insert_at_tail(list, data)` | Inserts at the **tail**; new node becomes the new tail (also handles empty list). |
| 3 | `insert_before(list, key, data)` | Inserts **before** the first node whose data equals `key`; if the key is the head, delegates to head insertion. |
| 4 | `insert_after(list, key, data)` | Inserts **after** the first node whose data equals `key`; if the key is the tail, delegates to tail insertion. |
| 5 | `insert_at_position(list, pos, data)` | Inserts at the **1-based position** `pos`; validates `1 ≤ pos ≤ length+1`, delegating to head/tail for the ends. |

Supporting functions: `search()` (find key node), `count()` (list length), `print()` (forward), `print_reverse()` (backward).

## Bug Fixed in Original

The `DLL(Node*, Node*)` constructor ignored its arguments and set both pointers to `nullptr`. It now sets `head` and `tail` from the arguments.

## Representations

Two versions are provided, identical in logic and prompts:

- **`Q10.cpp`** — pointer representation (`Node*` with `next`/`prev` pointers).
- **`Q10_array.cpp`** — linked-array representation: `data[]`, `next_index[]`, and `prev_index[]` (the doubly-linked "prev" as an index), from `THEORY/LL/LinkedArray/larray.cpp`. The head/tail are `START`/`TAIL` indices; `NIL (-1)` plays the role of `nullptr`.

## Test Cases

| # | Setup | Operation | Expected Output | Covers |
|---|-------|-----------|-----------------|--------|
| 1 | Empty list (`-99`) | — | `List: List is empty` | Empty list |

| 10 | `10 20 30` | Insert `15` at position `2` | `10 15 20 30` | Insert at middle position |

| 13 | `10 20 30` | Reverse print | `30 20 10` | Reverse traversal (prev links) |
| 14 | `-5 0 7` | Insert `2` after `0` | `-5 0 2 7` | Negative/zero values |

## Notes

- The list is a true doubly linked list: every node keeps both `next` and `prev`, and `DLL` tracks both `head` and `tail`, so forward and reverse traversals both work.
- Empty-list insertion is handled uniformly: the first node becomes both head and tail.
- Insert-before/after with a missing key prints `Key not found!` and leaves the list unchanged.
