# Q12. Delete a Given Node (No Head Pointer)

> **Question:** Write a function to delete a **given node** (a pointer to the node is provided), **without knowing the head pointer** of the list.

## Approach

Since we don't have the head (or a `prev` pointer), we can't unlink the node the usual way. The standard trick used here:

1. Copy the **next** node's data into the node we're deleting:
   ```
   ptr->data = ptr->next->data;
   ```
2. Unlink the next node from the list:
   ```
   ptr->next = ptr->next->next;
   ```
3. Free the next node.

Effectively, the *next* node is physically removed while `ptr` keeps its identity but now carries the next node's data — so the given node's *value* is gone and the list stays intact.

**Limitation (kept from the original):** the **last** node cannot be deleted this way — there is no next node to copy from. The program prints `Can't delete last node!` in that case.

## Bug Fixed

**Original bug:** the code did `ptr->next = ptr->next->next; delete ptr->next;`. After the rewiring, `ptr->next` already points to the *next-next* node, so `delete ptr->next` freed the **wrong** node — the copied node leaked and the list silently lost **two** nodes (the target's value and the successor).

**Fix:** save the real successor first, then unlink and free exactly that one node:

```cpp
Node *temp = ptr->next;
ptr->data = temp->data;
ptr->next = temp->next;
delete temp;
```

## Notes

- After deleting the head value, the physical head node is untouched — only its data changed — so no head pointer is ever needed.
- The last-node limitation is inherent to this technique (no head / no prev); the original program had it and it is intentionally preserved.
