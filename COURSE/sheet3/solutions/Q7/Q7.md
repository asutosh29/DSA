# Q7. Insert at a Given Position

> **Question:** If the position `K` of the data item to be inserted is provided **instead of** a key item, modify the above function accordingly so that the data item is inserted as the **Kth node**.

## Approach

`insert_at_kth(head, data, index)` uses a **1-based** index:

- `index < 1` → `Invalid position!`, list unchanged.
- `index == 1` → the new node becomes the new head.
- otherwise the loop advances `ptr` to the `(index-1)`th node (the node that should precede the new one). If the walk runs off the list first, the position is beyond the list length and the function reports `Position exceeds list length!` (the temporary node is deleted, no leak).
- otherwise the new node is spliced after `ptr`.

Because the head can change, the function returns the new head.

`main()` uses a simple loop: each iteration asks for an element to insert and the position `k`, prints the list, and repeats until the user enters `-99` to exit.

## Test Cases

| # | Input (one line each) | Expected Output | Covers |
|---|-----------------------|-----------------|--------|
| 1 | List `10 20 30`, then `5`, `k=1`, then `-99` | `5 10 20 30` | Insert at head (k=1) |
| 2 | List `10 20 30`, then `15`, `k=2`, then `-99` | `Inserted element 15 at index 2` → `10 15 20 30` | Insert in the middle |
| 3 | List `10 20 30`, then `40`, `k=4`, then `-99` | `Inserted element 40 at index 4` → `10 20 30 40` | Append at end (k = len+1) |
| 4 | List `10 20 30`, then `99`, `k=6`, then `-99` | `Position exceeds list length!` → `10 20 30` | k beyond len+1 |
| 5 | List `10 20 30`, then `5`, `k=0`, then `-99` | `Invalid position!` → `10 20 30` | k = 0 |
| 6 | List `10 20 30`, then `5`, `k=-2`, then `-99` | `Invalid position!` → `10 20 30` | Negative k |
| 7 | Empty list (`-99`) | Program exits with `List is empty!` | Empty list |

## Notes

- Positions are 1-based: `k=1` is the head, `k = length+1` appends.
- Inserting at `k = length+1` is allowed; only positions *beyond* that are rejected.
