# Q5. Insert After a Key Node

> **Question:** Write a function `insert_after()` which receives:
> - A head pointer to the first node of a linear linked list of integer items.
> - An integer data item to insert.
> - A key item.
>
> The function inserts the given integer data item **after** the node containing the given key.

## Approach

`insert_after(head, data, key)` walks the list looking for the first node whose data equals `key`. On finding it, a new node with `data` is created and spliced in right after it:

```
temp->next = ptr->next;
ptr->next = temp;
```

The head never changes (insertion is always after some node), so the head pointer is returned unchanged. If the list is empty, or the key is never found, the list is returned untouched with an appropriate message.

`main()` uses a simple loop: each iteration asks for an element to insert and the key after which to insert it, prints the list, and repeats until the user enters `-99` to exit.

## Test Cases

| # | Input (one line each) | Expected Output | Covers |

| 1 | List `10 20 30`, then `5`, key `10`, then `-99` | `10 5 20 30` | Insert after head |

| 4 | List `10 20 30`, then `99`, key `77`, then `-99` | `Key not found!` then `10 20 30` (unchanged) | Missing key |
| 5 | Empty list (`-99`) | `List is empty!` (program exits) | Empty list |
| 6 | List `7 7 9`, then `8`, key `7`, then `-99` | `7 8 7 9` (first occurrence) | Duplicate keys |
| 7 | List `10 20 30`, then `5` key `10`, then `40` key `30`, then `-99` | `10 5 20 30` then `10 5 20 30 40` | Multiple inserts in one run |

## Notes

- With duplicate keys, insertion happens after the **first** matching node.
- If the key is absent, the list is left completely unchanged.
