# Q14. Count Occurrences of a Key

> **Question:** Write a function to find the **number of occurrences** of a given key data item in the linked list.

## Approach

`count(list, key)` walks the whole list and increments a counter every time `node->data == key`. When the walk ends (including the empty-list case), it returns the total.

`main()` builds the list, prints it, then loops: each entered key prints its occurrence count until the user enters `-99`.

## Test Cases

| # | Input (one line each) | Expected Output | Covers |
|---|-----------------------|-----------------|--------|
| 1 | List `5 3 5 5`, query key `5` then `-99` | `Count of element 5 : 3` | Multiple occurrences across the list |
| 2 | List `1 2 3`, query key `9` then `-99` | `Count of element 9 : 0` | Key absent |
| 3 | List `7`, query key `7` then `-99` | `Count of element 7 : 1` | Single occurrence |
| 4 | List `-99` (empty), query key `5` then `-99` | `List is empty` → `Count of element 5 : 0` | Empty list |
| 5 | List `4 4 4 4`, query key `4` then `-99` | `Count of element 4 : 4` | All nodes equal |
| 6 | List `-3 -1 -1 2`, query key `-1` then key `-3` then `-99` | `Count of element -1 : 2` then `Count of element -3 : 1` | Negative keys, multiple queries |
| 7 | List `1 2 1 3 1`, query `1` then `2` then `5` then `-99` | counts `3`, `1`, `0` in that order | Several queries in one run |

## Notes

- Counts every occurrence, including duplicates at the head, middle, and tail — the scan always runs to the end of the list (O(n)).
- `count()` is a linear scan; there is no precomputed index, matching the original program.
