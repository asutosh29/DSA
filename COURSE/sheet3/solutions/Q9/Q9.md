# Q9. Josephus Problem

> **Question:** Write and test a function `Josephus()` to implement the Josephus problem using a linked list.

## Approach

The people are stored in a **circular linked list** (each `Node` holds a `char*` name, and the last node's `next` points back to the head). The user picks an entry-point soldier by name and a step count `N`.

`josephus()` repeatedly:
1. walks `N-1` steps forward around the circle from the current position (the current node **counts as step 1**),
2. deletes the node it lands on (`delete_node`),
3. resumes counting from the node that followed the deleted one,

…until only one node remains — the survivor, who is printed as the "Final person to exit".

> **Counting convention:** this program counts the *current node itself* as the first step. So with `N=2` and start `A`, the first node eliminated is `B` (A → B). (Some textbook versions count starting from the *person after* the entry point, which shifts the elimination order and can change the survivor — the test cases below match **this** program's convention.)

## Source

`COURSE/sheet3/9.cpp` — rewritten with core logic unchanged, but with three bugs fixed.

## Bugs Fixed

| # | Bug in original | Consequence | Fix |
|---|---|---|---|
| 1 | `delete_node()` assumed the node to delete always had a predecessor and dereferenced `prev` even when it was `nullptr` (i.e. when deleting the head) | **Crash / segfault** when the entry point was the head node | Head deletion is now handled specially: the tail is found and relinked to the new head before the old head is freed |
| 2 | `josephus()` did `ptr = ptr->next` **after** calling `delete_node(head, ptr)` | Use-after-free (reading freed memory — undefined behaviour) | The successor pointer is saved **before** deletion: `Node *nxt = ptr->next;` |
| 3 | `find()` / `josephus()` dereferenced `head` unconditionally | Crash on an empty list | `josephus()` now returns early with `List is empty!` |

## Representations

Two versions are provided, identical in logic and prompts:

- **`Q9.cpp`** — pointer representation (`Node*`), from `COURSE/sheet3/9.cpp`.
- **`Q9_array.cpp`** — linked-array representation (`data[]` + `next_index[]`), from `THEORY/LL/LinkedArray/larray.cpp`. The "head" is the `START` index; `NIL (-1)` plays the role of `nullptr`. The list stays circular: `next_index[tail] == START`.

## Test Cases

(For brevity, "names" below are entered one per prompt until `END`.)

| # | Input | Expected Output | Covers |
|---|-------|-----------------|--------|
| 1 | `A`, `END`; start `A`, `N=1` | `A` → loop condition `ptr != ptr->next` is false → `Final person to exit: A` (no deletions) | Single person |
| 2 | `A`, `B`, `END`; start `A`, `N=2` | Delete `B` → survivor `A` | Two people |
| 3 | `A B C D E`, start `A`, `N=2` | Deletions `B D A E` → survivor `C` (the program's counting convention: current node = step 1) | N=2 classic case |
| 4 | `A B C D E`, start `A`, `N=1` | Deletions `A B C D` → survivor `E` | N=1 — entry point deleted first (bug-case: start = head) |
| 5 | `A B C D`, start `C`, `N=3` | Counting starts at C: delete `A` (C→D→A), then `D` (B→C→D), then `B` → survivor `C` | Start from a middle node |
| 6 | `A B C`, start `X`, `N=2` | `Name not found in the list!` | Name not present |
| 7 | `END` (empty list) | `List is empty` then `List is empty!` | Empty list (no crash) |
| 8 | `A B`, start `B`, `N=1` | Delete `B` (head becomes `A`), then `Final person to exit: A` | Deleting the head does not crash |

## Notes

- The final survivor is printed as `Final person to exit:` — terminology inherited from the original program.
- `delete_node()` on a single-node list deletes the node and returns `nullptr`; `josephus()`'s loop naturally stops before that because `ptr == ptr->next` terminates the loop.
