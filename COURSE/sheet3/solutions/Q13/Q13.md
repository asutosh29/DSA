# Q13. Swap Kth Node from Beginning and End

> **Question:** Write a function to **swap** the `k`th node from the beginning with the `k`th node from the end of a given linked list.

## Approach

Only the **data** of the two nodes is swapped — the link structure never changes (this is the classic, simpler variant of the problem).

- `ptr1` (kth from the beginning): walk `k-1` steps from the head. If we run out of nodes first, print `k is greater than length of the list!` and return unchanged.
- `ptr2` (kth from the end): the **two-pointer trick** — after `end` is parked at the kth node, move both `start` (from head) and `end` one step at a time until `end` reaches the last node. At that point `start` is exactly the kth node from the end.
- Swap `ptr1->data` with `ptr2->data`.

## Notes

- The swap exchanges **data only**; no `prev` pointers or link rewiring is needed, which keeps the function O(1) extra space and O(n) time.
- When `k` equals the middle of an odd-length list, both pointers reference the same node and the list is unchanged.
- `k > length` prints a message and leaves the list untouched (the original's behaviour).
