# Q1. Basic Linked List Operations

> **Question:** Write the following functions:
> - `create()` — Create a linear linked list.
> - `print()` — Print the above list.
> - `count()` — Count the number of nodes in the above list.
> - `modify()` — Manipulate the record of each node (design left up to you).

## Approach

The program builds a linked list **recursively** — each call to `create()` reads one integer, creates a node, and links it to the result of the next call. Input stops when the user enters `-99`.

- **`create()`** — recursive construction; `-99` acts as the terminator.
- **`print()`** — walks the list and prints each node's data.
- **`count()`** — walks the list and counts nodes.
- **`modify()`** — loops, asking for an **index (1-based)** and a **new value** for the node at that index. It keeps asking until the user enters `0` to exit. Invalid indices are rejected with `Invalid index!`.

> The original `1.cpp` also contained a `bubble_sort()` + `swap()` — those are **not** part of the Q1 spec, so they have been **removed** from this solution.
